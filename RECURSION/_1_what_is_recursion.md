# Recursion

- It is a prgramming approach in which a function calls itself repeatedly.
- We decompose a big problem into similar small problems.
- We write the code to solve this one small problem and rest of the problem is solved by calling that function again. 

### Base case

- it is the case where we know the solution 
- when the base case is reached, the recursion stops

### Function call

- each function call gets to the stack and return the value to the previous function call
