# WHAT IS A GRAPH

- it is a data structure
- Graph contains various nodes connected to each other
- There is no hierarchy within the nodes, So graph is a network of nodes
- The connecting lines between any two nodes is called an edge
- The nodes are called vertex/vertices

## Practical examples where graph can be used to store the data

- In applications like Google Map, Uber, OLA 
- Social media applications
- For implementing the neural network
