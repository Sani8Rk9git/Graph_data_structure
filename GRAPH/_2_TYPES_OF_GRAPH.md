# Types of Graphs

## The edges that connect the nodes in the graph can be of the following types:

- ### Directed edges
    - The edges that points to some nodes in the graph
    - The edges can point to either of the connecting nodes
    - These edges are also known as uni-directional edges
    - These edges specify one way movement
    > A ---------> B
    
- ### Undirected edges
    - These edges connect the nodes in the both direction
    - These types of edges are also known as bi-directional edges
    - These edges specify two-way movement between the nodes
    > A ---------- B

- ### Weighted edges
    - The edges of the graph are associated with same weights
    - weights can be positive or negative values
    - weights mean some value is associated to the edges

- ### Unweighted edges
    - The edges are not associated with the weights


## Based on the edges we can have 4 types of graphs

- Undirected Unweighted Graph
- Undirected Weighted Graph
- Directed Unweighted Graph
- Directed Weighted Graph

## Connected Graph

- The graph in which each node is connected to some other node and there is a path that reach to each node from every node then that graph is connected graph

## Disconnected Graphs

- The graphs that have some nodes that are not connected to any of the other nodes are called disconnected graphs

- These graphs have two components within them
    - Connected Component
    - Disconnected Component
